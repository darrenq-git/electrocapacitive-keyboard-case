# Product design project: Electrocapacitive Mechanical Keyboard
<img width="4096" height="3072" alt="IMG_20261110_114646" src="https://github.com/user-attachments/assets/84e3ee47-00a2-460b-8c1c-f21f5d4cd55f" />

This project is a custom gasket-mount case and mounting plate for an electrocapacitive mechanical keyboard, designed with manufacturing in mind as a passion project and a chance to use engineering methods learnt from university. The case and plate were designed from scratch around a commercial PCB (YMDK Eevee#40B), poron gaskets, a LiPo battery, switches and keycaps. This repository contains the design report, CAD files and photos of what is currently built.

Full documentation and report is being written at the moment.
